# Mumbai WhatsApp Creative Pack (Editable SVG)

These are editable square creatives (1080x1080) for Channel and Community updates.

## Files

1. `01-official-scheme-update.svg`
2. `02-safety-fraud-alert.svg`
3. `03-reactivation-comeback-push.svg`
4. `04-top-driver-success-story.svg`
5. `05-join-official-channel-qr.svg`

## How to edit quickly

- Open SVG in Figma, Canva (import), Inkscape, or Illustrator.
- Replace placeholder text:
  - `<SCHEME_NAME>`
  - `<WINDOW>`
  - `<TRIP_TARGET>`
  - `<BONUS>`
  - `<HELPDESK_CONTACT>`
- Export PNG for WhatsApp sharing.

## Recommended use

- Channel: 1-2 creatives per day (avoid over-posting).
- Community: use safety and helpdesk creatives when confusion spikes.

## Branding notes

- Keep "Official" label on every operational creative.
- Always include anti-fraud footer on financial/incentive posts.
