# Driver Captain Program (Mumbai OLA Auto 3W)

Driver captains are your local growth engine.
They improve onboarding trust, reduce misinformation, and speed up reactivation.

## 1) Program objective

- Build reliable zone-level leadership.
- Improve driver retention and active hours.
- Increase reactivation conversion in each captain's zone.

## 2) Captain profile criteria

Minimum criteria:
- 3+ months platform familiarity (preferred)
- Positive communication behavior
- Basic smartphone literacy
- No recent policy violations
- Can commit 90 minutes/day for captain duties

Preferred:
- Known at local stand or route cluster
- Bilingual (Hindi + Marathi or Hindi + English)

## 3) Captain coverage model

Starting structure (for first 500-800 members):
- Western: 2 captains
- Central/Harbour: 2 captains
- South/Navi: 1 captain
- 1 reserve captain (floating support)

Total: 6 captains.

## 4) Captain responsibilities

Daily:
- Share 2 local demand signals (time + area + confidence level).
- Help onboard at least 5 drivers (verified joins).
- Support 3 inactive drivers with restart guidance.
- Flag scams/misinformation immediately.

Weekly:
- Submit zone insight summary.
- Join weekly review call.
- Mentor one new captain candidate.

## 5) Captain SOP behavior rules

- Only share verified information.
- Never promise fixed earnings.
- No private money collection or fee requests.
- Keep communication respectful and non-political.
- Escalate payouts/app issues to helpdesk, not personal claims.

## 6) Captain scorecard (weekly)

| Metric | Target | Weight |
|---|---|---|
| Verified joins | >= 30/week | 25% |
| Reactivation assists | >= 12/week | 25% |
| Useful demand signals | >= 10/week | 20% |
| Quality score (no false alerts/spam) | >= 95% | 20% |
| Attendance in review and SOP compliance | 100% | 10% |

Total score = weighted average.

## 7) Reward and recognition model

Use a transparent monthly model:

- Gold Captain: score >= 90
- Silver Captain: score 80-89
- Bronze Captain: score 70-79

Reward options (as policy allows):
- official recognition post in group/channel
- certificate/badge
- priority support handling
- approved incentive top-up or voucher

## 8) Anti-gaming checks

Prevent fake joins and low-quality activity:

- Random audit 10% of join records weekly.
- Count only verified joins (driver remains for >48 hours).
- Reject duplicate contacts and self-referrals.
- Penalize false hotspot claims after repeated incidents.

## 9) Captain lifecycle

1. Nomination (field lead + community lead)
2. 7-day probation
3. Active status with weekly scorecard
4. Monthly renewal or replacement

## 10) Captain communication stack

- One private captain coordination group (admins + captains only)
- Standard format for signal posting:

```
Zone:
Time:
Location:
Demand level (Low/Medium/High):
Reason (station rush, event, weather, etc.):
```

## 11) Monthly captain review agenda

1. Performance by zone
2. Top 3 wins
3. Top 3 operational issues
4. Process changes for next month
5. Captain promotions/replacements
