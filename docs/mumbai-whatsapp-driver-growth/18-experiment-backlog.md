# Experiment Backlog (Traction and Optimization)

Use this backlog during weekly reviews. Pick 2-3 experiments per week.

## Prioritization rule

Score each experiment on:
- Impact (1-5)
- Ease (1-5)
- Confidence (1-5)

Priority score = Impact x Ease x Confidence.

## A) Content experiments

1. **Post timing split test**
   - Hypothesis: 08:30 gives higher reach than 09:30.
   - KPI: 24h view rate.
   - Run for: 7 days.

2. **Language mix test**
   - Hypothesis: Roman Marathi + Hindi blend improves engagement in selected zones.
   - KPI: reaction rate and helpdesk reply rate.
   - Run for: 10 days.

3. **Short vs detailed format**
   - Hypothesis: short 5-line posts increase comprehension.
   - KPI: scheme completion conversion.
   - Run for: 7 days.

## B) Reactivation experiments

4. **DM first vs call first for 30+ inactive**
   - Hypothesis: call-first gives better conversion for long-inactive users.
   - KPI: 7-day reactivation conversion.
   - Run for: 2 weeks.

5. **Low-threshold comeback challenge**
   - Hypothesis: day-1 target reduction increases re-entry rate.
   - KPI: first-day online return rate.
   - Run for: 10 days.

6. **Zone-personalized plan vs generic plan**
   - Hypothesis: zone-specific nudges improve reactivation confidence.
   - KPI: response rate and resumed trips.
   - Run for: 2 weeks.

## C) Acquisition experiments

7. **QR placement at fuel-payment counter vs entry gate**
   - Hypothesis: payment counter yields better scan conversion.
   - KPI: scans to verified joins.
   - Run for: 2 weeks.

8. **Captain-led onboarding windows**
   - Hypothesis: 08:00-10:00 and 18:00-20:00 windows produce max joins.
   - KPI: joins per captain-hour.
   - Run for: 1 week.

9. **Partner incentive recognition**
   - Hypothesis: weekly top-partner recognition increases support from location staff.
   - KPI: partner location conversion rate.
   - Run for: 1 month.

## D) Operations quality experiments

10. **Helpdesk triage tags**
    - Hypothesis: pre-defined tags reduce response time.
    - KPI: FRT and same-day resolution.
    - Run for: 2 weeks.

11. **Shift overlap 30 minutes**
    - Hypothesis: overlap reduces missed escalations.
    - KPI: open escalations end-of-day.
    - Run for: 10 days.

12. **Captain daily voice-note briefing**
    - Hypothesis: voice-note briefing increases local signal quality.
    - KPI: useful signal count and engagement.
    - Run for: 1 week.
