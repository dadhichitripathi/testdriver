# Message Templates (Roman Hindi + Roman Marathi + English)

Use these templates directly in WhatsApp Channel and Community groups.
Replace placeholders in `<...>`.

## 1) Channel: scheme update template

### Roman Hindi
```
OLA Auto Mumbai Update (Official)
Scheme: <scheme_name>
Eligibility: <conditions>
Window: <start_date_time> se <end_date_time>
Zones: <zones>
Target: <trip_target>
Bonus: <amount>
Example: <trip_target> trips complete karo, extra <amount> pao.
Help: <helpdesk_group_or_number>
```

<trip_target> trips pe approx <amount> extra possible hai.
Need help? Reply karo, hum guide karenge.
```

```
Hi <name>,
Aaj <zone> madhye <time_window> madhye demand jast aahe.
<trip_target> trips var approx <amount> extra milu shakto.
Madat pahije asel tar reply kara.

Hi <name>,

Reply if you want a quick plan.

## 3) Helpdesk reply templates

### Eligibility confusion
```
Thanks for checking.
Your current eligibility is: <eligibility_status>.
To unlock bonus, complete: <remaining_condition>.
Time left in window: <time_remaining>.
```

### Payout delay
```
Noted. Please share:
1) Driver ID
2) Date and time of completed target
3) Screenshot of trip summary
We are escalating this with priority and will update by <eta>.
```

### App issue
```
Understood. Please try:
1) Force close and reopen app
2) Check network and location permissions
3) Update app to latest version
If issue remains, share screenshot and error text.
```

## 4) Moderation templates

### First warning
```
Admin note:
Please keep group messages relevant to trips, schemes, and support.
Off-topic or spam messages are not allowed.
```

### Scam alert broadcast
```
Safety alert:
Any message asking for OTP, UPI transfer, or login password is fraud.
OLA team will never ask for payment in this group.
Report suspicious messages to admin immediately.
```

### Removal notice
```
Admin action:
User removed due to repeated policy violations (spam/abuse/fake info).
Please follow group rules for a safe and useful community.
```
